VAZ 2110 FULL DASHBOARD — Android Launcher project
===================================================

Мүмкіндіктер:
- Тірі GIF фон (түнгі трассадағы VAZ 2110).
- Нақты уақыт пен күн.
- VAZ 2110 / KZ 244 AEK 04 белгісі.
- Музыка қолданбасын ашу және жүйелік Play/Pause медиа пәрмені.
- Google Maps / навигацияны ашу.
- Bluetooth баптауларын ашу.
- Қосымшалар мен Android Settings-ке өту.
- Landscape / көлденең экранға арналған интерфейс.
- HOME Launcher ретінде тіркеледі: әдепкі Home ретінде таңдасаңыз, магнитола Home батырмасын басқанда осы экран ашылады.

APK құрастыру:
1) ZIP-ті компьютерге ашыңыз.
2) Android Studio → Open → VAZ2110_Full_Dashboard бумасын таңдаңыз.
3) Gradle Sync аяқталған соң Build → Build Bundle(s) / APK(s) → Build APK(s).
4) app/build/outputs/apk/debug/app-debug.apk файлын магнитолаға көшіріп орнатыңыз.
5) Android Settings → Apps → Default apps → Home app ішінен
   "VAZ 2110 Dashboard" таңдаңыз.

Маңызды:
- Бұл Android Studio жоба-коды; дайын APK емес.
- Магнитолаңызда Android 6.0+ болуы және Android қолданбаларын орнатуды қолдауы керек.
- Launcher-ді әдепкі Home етіп таңдағанда, Home батырмасы осы интерфейсті ашады.
- Android қауіпсіздік шектеулеріне байланысты құрылғы қосылғанда фондық түрде автоматты іске қосылуға кепілдік жоқ; әдепкі Home launcher ретінде таңдау — дұрыс тәсіл.
- Музыка Play/Pause командасы магнитолада белсенді медиа ойнатқыш болса жұмыс істейді.
- Навигация Maps немесе құрылғыдағы қолжетімді карта қолданбасын ашады.
- Ауа райы онлайн API қоспайынша көрсетілмейді; бұл нұсқада live clock/date бар.
